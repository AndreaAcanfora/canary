canary

A $4 dead man's switch for your home.

An ESP32 that sends a heartbeat every minute. When the power goes out, the freezer warms up or water reaches the floor, the heartbeat stops or turns red, and your phone knows.

Installing from the browser needs Chrome or Edge on a computer. You can also flash it with esptool. Open this page over https to install. GitHub

Plug the board in with USB, click Install, pick your Wi-Fi. No toolchain, no account with us.

Things it watches

Power and internet

Plug it into a wall socket. If heartbeats stop, the power or the connection is gone. When it comes back, the first heartbeat says boot=power-on.

Freezer and fridge

A DS18B20 probe through the door seal. Alert above −15 °C, only if it lasts 10 minutes, so opening the door is fine.

Leaks and pumps

Any switch: a leak sensor, a float switch in the sump, a door contact. The alert goes out the second it trips.

    How it works

    1. SenseOnce per second the board reads its probes.
    2. BeatIt sends POST /ping/… every minute, and /fail at once when something is wrong.
    3. WatchA heartbeat server expects the beat. Silence or a fail means trouble.
    4. AlertThe server notifies you: push, email, Telegram, ntfy.

    canary speaks the Open Heartbeat Protocol, the URL scheme that Healthchecks.io and similar services already use. Paste a ping URL from Healthchecks.io (the free plan has 20 checks) or run your own server: ohp serve, or self-hosted Healthchecks.

    Setup

    1. Click Install on an ESP32, choose the serial port, then your Wi-Fi network.
    2. Open the setup page it links to (or http://canary.local).
    3. Add a probe, paste a ping URL, save. The status LED flashes briefly every 3 s when all is well.

    The setup page only accepts changes for 15 minutes after power-on or after pressing BOOT. Ping URLs are secrets, so they are hidden after that.

    No ESP32? Use a Raspberry Pi

    The same probes run on Linux and read any number from a file: a 1-Wire sensor, a GPIO, the CPU temperature.

    probe1.type=temp
probe1.url=https://hc-ping.com/your-uuid
probe1.source=/sys/class/thermal/thermal_zone0/temp
probe1.scale=0.001
probe1.max=80
